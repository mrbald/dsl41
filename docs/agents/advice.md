# Advise on one question

For the advisor and maintainers assigning a bounded design question.
Read the [shared contract](../../CLAUDE.md) and the evidence named in the brief.
The boss supplies the question and owns the ruling.

- Stay read-only and within the named question. Call no other model.
- Test the proposed answer against the constraints and a concrete failure case.
- State the recommendation, supporting evidence, uncertainties and tradeoffs.
- Return it to the boss through the operator. Do not accept a candidate, change
  scope, dispatch work, or make a release decision.

The [coordination guide](coordination.md#operating-model) owns the binding.
Read it only if the task concerns that binding.
